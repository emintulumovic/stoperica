# Štoperica

Projekat urađen u Flowcode-u. Simulira digitalnu štopericu sa LCD ekranom koja mjeri i prikazuje proteklo vrijeme.

## Kako radi

Vrijeme se prikazuje u formatu MM:SS:ss (minute, sekunde, stotinke). Upravljanje je putem četiri tastera:

| Taster | Funkcija |
|--------|----------|
| Start | Počinje mjerenje |
| Stop | Pauzira mjerenje |
| Lap | Sprema trenutno međuvrijeme |
| Reset | Resetuje brojač na nulu |

## Tehnologije

- Flowcode
- PIC mikrokontroler
- LCD displej 16x2
